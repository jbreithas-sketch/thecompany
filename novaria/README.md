# NOVARIA

Offline-first narrative educational adventure for Android and iOS.

## Architecture
Expo Router, React Native, TypeScript. Pure deterministic domain engines separated from UI and persistence. SQLite planned for native saves. No account, advertising, tracking or paid runtime AI. Cloud sync deferred and opt-in.

## Layout
- src/app: routes
- src/domain: story, relationships, learning, world and inventory
- src/content: versioned chapters and learning objectives
- src/storage: versioned save adapter
- src/components: reusable UI
- assets: original fantasy illustrations

## Acceptance
Three playable chapters, four heroes, five companions, three meaningful branches, fifteen learning objectives, three learning mechanics, offline saves. Master concept and pedagogical review pending. Exclude previously rejected sibling character illustrations and associated style.

## Status
Foundation only; native build and device tests pending. No paid services authorized.
